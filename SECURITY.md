# Security

Please do not report security vulnerabilities or private-data exposure through public GitHub issues.

Relevant areas include:

- credentials and tokens;
- GitHub Actions permissions;
- workflow, artifact, or cache leakage;
- public/private data-boundary violations;
- manager-specific data disclosure.

Manager-specific state must never be published through public repository files, logs, caches, artifacts, or releases.

Use GitHub Private Vulnerability Reporting where available. If it is unavailable, contact the repository owner privately.
